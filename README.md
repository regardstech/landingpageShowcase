# RAW STAR Clothing - Landing Page

A fast, responsive, mobile-first e-commerce landing page with direct WhatsApp ordering and interactive features.

## Deployment on Vercel

### Option 1: Vercel CLI (Instant)
```bash
npx vercel
```
Or for production deployment:
```bash
npx vercel --prod
```

### Option 2: GitHub / Git Repository Import
1. Push this directory to your GitHub/GitLab/Bitbucket repository.
2. Go to [vercel.com/new](https://vercel.com/new).
3. Import the repository.
4. Framework Preset: **Other** (Static Site). No build command or output directory configuration is needed.
5. Click **Deploy**.

## Project Structure
- `index.html`: Main landing page (HTML5 + Tailwind CSS CDN + Alpine/Vanilla JS)
- `vercel.json`: Vercel routing configuration & long-term static asset caching
- `package.json`: Project metadata
- `Resourses/`: Static image assets & links
